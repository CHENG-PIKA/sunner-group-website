# 圣农集团企业官网

静态网页项目，由提供的“圣农集团官网.html”整理而成，保留原有页面、图片、视频与交互。原文件中内嵌的媒体已无损独立保存。

## 本地运行

无需安装依赖或构建。在项目目录运行：

```sh
python3 -m http.server 8000
```

在浏览器打开 `http://localhost:8000/`。请使用 HTTP/HTTPS 服务访问；直接双击 HTML 时，浏览器会限制视频分片读取。

## GitHub Pages

本仓库是网站源文件，上传仓库本身不会自动公开为网站。若账号与仓库设置支持 GitHub Pages，可在 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`。所有栏目使用 `#/` 路由，支持项目子路径。

## 文件与视频

- `index.html`：网页样式、页面内容与交互
- `assets/`：图片、LOGO、视频及视频分片
- `.nojekyll`：允许 GitHub Pages 直接发布静态文件

两段较大视频拆成小于 20 MiB 的 `.part-*` 文件，以便通过 GitHub 网页上传。选择相应视频后，浏览器才会读取分片，校验完整性并按原顺序恢复为 MP4；没有压缩、转码或降低画质。首页第一段短视频直接播放，其他视频加载时保留原海报。分片恢复结果会在当前浏览会话中复用。

请保留完整 `assets/` 目录。页面文案与功能沿用提供文件，部分内容仍包含原有占位说明。
